# Day 3 – Maven Project Setup & FR Console Menu

## Completed Tasks

- Converted HorizonHR into a Maven parent project.
- Configured the parent `pom.xml` with `pom` packaging.
- Verified the Maven project using `mvnw clean compile`.
- Created a console menu representing all 8 Functional Requirements.
- Kept the console menu minimal as a temporary implementation for the HCL task.

## Functional Requirements

1. Employee & Department Management
2. Check In / Check Out
3. Apply for Leave
4. Validate Leave Request
5. Approve / Reject Leave
6. Manage Leave Balance
7. Manage Holidays & Leave Policies
8. View Team Attendance Report

## Key Learning

- Maven project structure
- Parent POM and `pom` packaging
- Difference between a Maven parent project and a runnable application
- Understanding how the daily HCL requirements map to the final HorizonHR architecture

## Note

The console menu is a temporary requirement implementation. It will be removed when HorizonHR evolves into the final Spring Boot microservices architecture.
